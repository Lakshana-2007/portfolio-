# Portfolio Starter

A polished portfolio website starter built with HTML, CSS, and JavaScript.

## Files

- `index.html` — the portfolio landing page
- `styles.css` — modern responsive styling with gradients, cards, and mobile navigation
- `script.js` — navigation toggle, form interaction, and scroll reveal animation

## Usage

1. Open `index.html` in your browser.
2. Replace the name, email, project descriptions, and content with your own details.
3. Optional: host on GitHub Pages or any static site platform.

## Notes

- The contact form is styled for interaction but does not send email by default.
- You can connect it to a form provider or backend endpoint later.
